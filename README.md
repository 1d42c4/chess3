# Chess3 — Improved Boards PDF Course Library

A chess study library with **122 PDFs** and **4 text indexes and QA files**. It includes 41 numbered subjects with matching course books and training workbooks, plus a complete White **1.d4/2.c4 repertoire** with 20 study modules.

## Start reading

1. Open the [Course Library Index](Course%20Library%20Index.txt).
2. Choose a numbered subject folder.
3. Read **00 - Complete Course Book.pdf**, then work through **01 - Active Training Workbook.pdf**.

For the White repertoire, follow its [Course Index and Study Order](1%20d4%202%20c4%20Complete%20White%20Repertoire/00%20-%20Course%20Index%20and%20Study%20Order.txt). The top-level index covers the 41 numbered subjects; the White repertoire has its own index.

## Main subjects

- **01–08 and 12–26:** major openings for White and Black, including the Ruy Lopez, King's Indian systems, Queen's Gambit, Sicilian, Caro-Kann, Hippopotamus and other defenses.
- **09–11:** positional chess, solid chess and improvement toward 2200 Elo.
- **27–34:** tactics, calculation, pawn structures, planning, piece improvement, attack, defense and initiative.
- **35–41:** endgames, conversion, time management, game analysis and tournament preparation.
- **Complete White repertoire:** 1.d4/2.c4 systems, common defenses, model plans and training workbooks.

## Download

Select **Code → Download ZIP** for the whole library (about 442 MiB of uncompressed source files), or open an individual PDF and select **Download raw file**. The PDFs can be saved to a phone, tablet or computer for offline reading. All files in this repository are stored directly in Git.

## Changes and protection

The default branch is protected against force pushes and branch deletion. Changes go through a pull request, with no user or app bypass exemptions. Independent review approval is not required, so the owner can maintain the library without another collaborator.

Files can still be edited or deleted through a merged pull request. The owner can change the protection rules or delete the entire repository. Keep a local copy of material you want to retain.

## Use and corrections

Follow the licenses, credits and reuse instructions included with each collection. If you find an error, identify the course, file, page or section, and the move or explanation that needs correction.
